For Almighty Musicals, I developed a custom wholesale platform to streamline B2B orders for Indian musical instruments, targeting music stores, event organizers, and international distributors.

The application is built using **React**, **Vite**, and **Firebase**, ensuring a fast, secure, and modern user experience. The platform includes features like dynamic inventory listings, supplier order management, traceability integration, and a contact-driven quote system in place of traditional e-commerce.

This project was tailored specifically for non-retail bulk transactions, allowing clients to browse, request quotes, and manage inventory with clarity and ease. I also implemented user-friendly forms and admin tools for managing stock, orders, and customer communication.

Almighty Musicals is now a scalable foundation that supports operational efficiency and growth for our wholesale music business. The website is ready to launch and is currently hosted at [main.d2zwc2np4txide.amplifyapp.com](https://main.d2zwc2np4txide.amplifyapp.com/), awaiting final inputs from the client.
